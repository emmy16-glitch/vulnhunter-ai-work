Start a Source Hunt

Three governed steps

  1. 1
    Bind the exact snapshot

    Choose an approved repository root, revision and permitted repository paths. Symlinks, unstable reads, oversized files and paths outside the approved root fail closed.

  2. 2
    Confirm source processing

    Re-authenticate and attest that the bounded source excerpts may be sent to the configured advisory provider under the recorded retention/data controls.

  3. 3
    Queue the worker

    A separate persisted worker performs the hunt → falsification → capability filter. Navigation or a browser timeout does not restart the task.

Authority stays with VulnHunter.

Groq is advisory only. It cannot authorize a repository, execute code, verify a finding, set final severity, merge a fix or publish a result.
